## 발견·수정

- 높음: 타 시도와 타 시군의 지방정부 사업을 추천에서 제거하지 않고 ‘확인 필요’로만 남겼다. 지원지역 판정을 공통 코드로 옮기고, 명확한 타지역 사업을 페이지 계산 전에 제외한다.
- 높음: K-Startup 공식 지원지역이 메모에만 있어 필터에서 사용되지 않았다. 공식 지원지역을 기관 지역보다 우선한다. 전국·복수 지역·해석 불가능한 범위를 일부 지역으로 축소하지 않는다.
- 높음: 추가 채널의 region=null 때문에 지방정부 관할 정보가 무시됐다. 공식 기관명의 시도·시군구를 확인한다. 중앙·공공기관의 이름 속 지명은 추측하지 않는다.
- 중간: 시군구를 포함 문자열로 비교하고, 결과 제외에는 사용하지 않았다. 시→구의 행정 단계별 이름을 비교한다. 시만 입력한 경우 구는 미확인으로 남긴다. ‘화성’과 ‘화성시’, ‘경기도 화성시’ 표기를 처리한다.
- 중간: 시도를 변경해도 이전 시군구가 남았다. 변경 시 초기화하고, 시군구만 입력하면 시도 선택을 요청한다. API는 서로 다른 시도가 함께 들어오는 입력을 거부한다.
- 중간: 지역 제외를 공통 추천에 넣으면 저장 목록에서도 항목이 사라질 수 있었다. 저장 목록은 보존하고 현재 조건과 불일치로 재평가한다.

전국민 대상·공식 전국 범위·명시된 전입 또는 사업장 이전 가능 공고는 기관 주소가 다르다는 이유로 제외하지 않는다. ‘이전 불가능’을 ‘가능’으로 오인하지 않는 회귀 테스트를 포함했다.
