# 전체 리뷰 수정 결과

발견한 7건을 수정했다. 기존 수집본과 영속 AI 호출 DB는 삭제하거나 초기화하지 않았다.

| 문제 | 변경 | 검증 |
|---|---|---|
| 개발 DB 노출 | Vite 전달 전 실제 경로 검사 및 fs.deny. private·SQLite·보조파일·심볼릭 링크 차단 | 가짜 DB의 직접·인코딩·절대 경로·WAL·링크 요청 거부, 정상 JS 제공 유지 |
| 임의 경로로 요청 제한 소진 | 유효 경로·메서드 먼저 검사. 고정 라우트별·IP 전체 제한. IP 저장소 포화는 오래된 항목 교체 | 미존재 경로 5,000회 뒤 정상 catalog 200 |
| 기관 지역으로 전국민 제도 누락 | 추천에서 기관 지역 하드 필터 제거. 타지역 주민 전용 후보는 실제 지역 확인 필요로 표시 | 실제 예산사랑상품권을 서울 프로필에도 보존, 지역 주민 전용은 unknown |
| 한국어 청크 손상 | 바이트 수를 제한하고 합친 뒤 엄격한 UTF-8 디코딩 | 한국어·이모지의 모든 바이트 분할, 크기 초과·잘못된 UTF-8 거부 |
| 과거·부정·충돌 조건 오인 | 애매한 나이·지역·금액을 null/unknown으로 유지. 여러 가족의 나이도 확인 대상으로 보류 | 과거 나이, 부정 거주지, 변경 소득, 복수 금액·가족 나이 회귀 사례 |
| 페이지 안에서만 분야 필터 | resultTopic을 서버에 전달해 필터 후 페이지 계산. 다음 페이지에도 필터 유지 | 서로 다른 두 페이지의 분야·전체건수·중복 여부, 실제 브라우저 주거 탭 1→2페이지 |
| 담은 혜택의 과거 평가 | 서버·브라우저 공통 추천 함수로 현재 조건 재평가. 공식 체크 원문과 파생 체크 분리 | 재평가 시 과거 미확인 체크 제거. 브라우저 창업에듀 25→5세 변경 후 일치1→불일치1 |

검증: `npm test` 59개 통과, `npm run build` 통과. Aside에서 직접 분야 선택·복수 분야 검색·페이지 이동·담기·조건 수정·재평가를 확인했다. 검증에 유료 외부 AI는 호출하지 않았다.

원문의 의미·자격을 모두 해석하는 범용 자연어 파서는 아니다. 확실하지 않은 값은 사용자가 확인 화면에서 직접 입력한다. 실제 공개 Turnstile·Google Cloud IAM/Spendcap·대규모 다중 사용자 부하는 이번 수정에서 검증하지 않았다.
