# 온혜 웹 시제품

2026-10-28. 사용자 확정: 상황을 입력하면 놓칠 만한 국가 복지혜택을 안내하는 웹, AI는 Jev 공개 접근을 독립 구현한 구조화 분류 + Google Cloud Gemini API, 후불 필수. 구현 지시는 ㄱㄱ. UI 이름·React/Vite 및 Node 서버는 구현 선택.

## 범위와 흐름

상황 입력 → 관심 분야 확인 및 나이·지역·취업상태 보완 → 근거가 있는 제도 후보 → 공식 안내·신청 경로. 자격·지급액을 확정하지 않는다. 이름·주소·주민번호는 요구하지 않는다. 상담은 메모리에서만 유지하고 재시작/새로고침 시 지운다.

## 대안과 선택

- Gemini로 복수 독립 Choice 질문을 분류하고, 원문 근거·고정 스키마를 검증한다. 모호하면 사용자 확인으로 넘긴다.
- 질문·안내 문구는 고정 템플릿이며 수급자격·금액을 생성하지 않는다.
- 미설정 시 규칙 기반 체험을 제공하며 실제 AI 오류를 체험 결과로 대체하지 않는다.
- Jev의 학습 가중치·확률 보정·다른 질문 유형은 복제하지 않는다. 현재 복지 흐름에 필요한 Choice 구조만 독립 구현한다.

## 데이터와 한계

2026-10-28 정부24 공공서비스(혜택) API의 전체 10,946개를 수집했다. 공식 전체 건수와 유일 ID를 검증하며 실패 시 기존 파일을 유지한다. 중앙행정기관·지자체·공공기관·교육청 등을 포함하지만 API 미등록 민간사업이나 현재 접수 여부는 보장하지 않는다. 검색은 20개씩, 상세는 선택 시 조회한다. 추천은 분야·알려진 기관 지역으로 좁힌 후보 중 최대 30개와 전체 후보 수를 제공한다.

## 결제

TypeSafe 직접 API는 선불이므로 제거했다. Google Cloud 계정 화면의 ‘후불 - Google Cloud 서비스’를 확인했다. AI Studio 경로는 사용하지 않는다. 전용 프로젝트 생성은 개수 한도로 막혀, 사용자 승인으로 기존 Gemini API 프로젝트(gen-lang-client-0179618980)를 사용한다. 이미 활성화된 Vertex AI API와 후불 결제 계정을 재사용하며 기존 인증 파일·클라우드 서비스 설정은 수정하지 않았다. 6개 합성 입력의 실제 호출 결과는 docs/gemini-live-check.json에 기록했다.
