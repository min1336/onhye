# 추천 개선과 평가 범위 (2026-10-29)

## 적용 원칙

[NIST AI RMF MEASURE](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)의 반복 가능한 평가·한계 명시·사용자 검증 구분 원칙을 적용했다. 수급자격 판정과 탐색 우선순위를 분리한다. 순위 점수를 확률·수급가능성 백분율로 표시하지 않는다.

- AI가 입력에서 찾은 관심 분야와 인용 근거를 확인 화면에서 보여주고 수정할 수 있다.
- 후속 입력 버튼은 현재 비교·순위 반영에 사용하는 정보만 요청한다. 자동 비교하지 않는 소득·가구 조건은 원문 확인 질문으로 안내한다.
- 나이·재산·가구 정보를 AI가 추측하지 않는다. 상세 조건 입력은 AI에 보내지 않는다.
- 취업·재학 상태, 사용자가 선택한 관심 분야와 주거 목적을 우선 후보 선정에 반영한다.
- 원문 확인 질문을 정리한 주요24개 제도가 관련된 경우 해당 범위에서 최대5개만 먼저 제시한다. 관련 없는 항목으로5개를 채우지 않는다. 그 밖의 제도는 전체 탐색에서 유지한다.
- 모집 종료·공개 마감일 경과·전입 예외·확인한 조건 불일치·목록만 수집한 자료는 우선 후보에서 제외한다. 전체 탐색·종료 공고 확인 경로는 유지한다.
- 국가장학금 I·II유형 등 같은 묶음은 우선 후보의 중복을 줄이며, 상세한 유형별 자료는 전체 탐색에서 보존한다.
- 아동수당·아이돌봄은 아동 나이를 별도로 비교한다. 첫만남이용권·임신출산 진료비처럼 제공 연령과 대상자 기준이 혼재하는 경우 자동 연령 판정을 보류한다.
- `server/program-guides.json`의 설명은2026-10-28 수집한 대상·선정조건 원문을2026-10-29에 정리한 개발용 안내다. 전문가 검수나 현재 모집 여부 확인을 뜻하지 않는다. 대상·선정조건 SHA-256이 변경되면 기존 안내를 적용하지 않는다.

## 재현

```sh
npm test
npm run evaluate:recommendations
node scripts/evaluate-recommendations.mjs --baseline
```

- 상황 파일: `research/evaluation/relevance-cases.json`
- 변경 전 결과: `research/evaluation/baseline.json`
- 변경 후 결과: `research/evaluation/current.json`
- 변경 전 알고리즘: `research/evaluation/baseline-recommendation.mjs`, `baseline-eligibility.mjs`
- 전체 수집본에서 종료 표시를 제외한 동일 후보군으로 서울·경기·부산의 구직·월세·보증금·생계·노후·장학·양육·장애·문화·예비창업 상황30개를 점검했다. 기존 시스템은 아동 나이·주거 목적 필드가 없어 해당 정보를 받지 못했다.

## 수치의 의미

사전에 지정한 기본 제도 ID 중 하나가 우선 후보 최대5개 안에 나타나는 상황 수는 변경 전0/30, 변경 후30/30이었다. 변경 전 알고리즘을 별도 파일로 보존했고, 동결한 결과가 재현되는지 확인했다.

**이는 자체 개발용 회귀 점검이다. 안내 목록을 추천에 직접 사용하므로 독립적인 성능평가가 아니다.** 지정 ID 외에도 유용한 지역사업이 있을 수 있어 변경 전0/30을 추천 오답률100%로 해석하면 안 된다. 변경 후30/30 역시 수급자격 정확도100%, 전체 정책 추천 정확도, 사용자 탐색 개선 또는 AI 모델 성능을 뜻하지 않는다. 사례는 합성 상황이며 실제 이용자 수는0명이다. 유료 모델 호출을 통한 AI 분류 비교 실험도 수행하지 않았다.

일반화 확인을 위해 미정리 신규 제도·입력 누락·부모/아동 나이·종료일·전입 예외·저장목록·페이징·관심 미확인 상황은 별도 테스트로 점검했다. 전체94개 테스트가 통과했다.

## 다음에 필요한 실제 사용자 검증

- 대상: 화성시 청년 구직자 등 한 집단5~10명, 자발적 참여와 필요한 동의를 먼저 확보.
- 과제: 개인정보 없는 같은 지원 탐색 과제를 기존 공식 검색과 온혜에 제시. 과제와 서비스 순서를 교차 배정.
- 지표: 적절한 지원 후보를 찾기까지의 시간, 상위 후보의 관련성, 조건·기한 이해도, 근거 없는 자격 확신, 도움 요청 횟수.
- 검수: 대상·제외조건·현재 모집 여부는 실험일의 공식 원문으로 별도 판정. 독립 검수자가 없으면 개발자 자체 검수임을 명시.
- 기록: 실패·포기·무응답을 제외하지 않고 표본 수·일자·실험 절차를 함께 보존. 개선률은 실제 관측 후에만 보고.
