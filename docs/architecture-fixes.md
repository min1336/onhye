# 2026-10-29 구조 리뷰 수정

- 연령: 원문 검증 가이드가 우선한다. 가이드가 없고 17세 이하 범위이며 원문·제도명에 아동·유아·보육 대상이 명시된 경우 아동 나이로 비교한다. 아동 나이 미입력은 추가 확인으로 남긴다. 이 보수적 텍스트 규칙은 전체 제도의 수급자격을 검증한 것은 아니다.
- 지역: 기업 소재지 조건은 거주지가 아닌 별도 사업장 입력으로 비교한다. 사업장 정보가 없으면 지역 불일치로 제외하지 않는다. 복합 지역·이전 조건은 기존 원문 확인 정책을 유지한다.
- 분야: 새 조건 검색은 전체 탭으로 시작하며 페이지 이동은 현재 탭을 유지한다. 서버도 명시적으로 선택한 분야와 결과 탭의 모순을 거절한다.
- AI 장애: 완료 기록 실패는 안전한 오류 로그를 남기며 성공한 AI 응답과 제공자의 원래 오류를 보존한다. 완료 기록을 못 남긴 예약은 기존 1분 동시성 시간창이 지나면 동시성 제한에서 빠진다. 일일 호출 예산은 되돌리지 않는다.
- 검색: 공개 검색 제한을 Firestore 조건부 갱신으로 공유한다. 저장소 장애 시 보호 대상 검색은 503이다. 추천은 날짜·프로필·분야·종료 포함 조건을 해시한 키로 30초간 인스턴스 메모리에 최대 두 조합을 보관한다. 페이지 번호는 키에서 제외하며 AI를 호출하지 않는다.
- 데이터: 수집 스크립트가 배포본을 재생성하고, 로컬 빌드·공식 배포 명령도 재생성한다. Vercel에서는 압축본·목록·해시를 검증한다. 임의로 원본 파일을 편집한 뒤 공식 배포 명령을 우회하면 최신 원본 포함을 보장하지 않는다.
- 모니터: 실행 잠금과 고유 임시 파일로 동시 실행·부분 상태 파일을 막는다. 비정상 종료로 남은 잠금은 프로세스 확인 후 수동 복구한다.

검증: 기존 94개 및 신규 7개 회귀 테스트 통과. AI 장애 테스트는 제공자 모형을 사용하며 유료 호출을 하지 않는다. 패키지 테스트는 임시 디렉터리에서 원본 변경·압축본 변조·목록 변조를 검출한다.
