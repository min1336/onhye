# 온혜

내 상황을 입력하고, 관련된 복지제도와 확인할 조건을 찾아보는 웹 시제품입니다.

## 현재 동작하는 범위

- 상황 입력 → 관심 분야 선택·수정 → 나이·지역 등 선택 입력 → 제도 후보
- 공식 선정조건·신청 안내·출처 링크 확인
- 관심 혜택 담기·필터·텍스트 안내 메모 저장
- 정부24·K-Startup·추가 채널의 실제 수집본 이름·기관·요약 검색, 분야·기관 지역·유형 필터, 20개씩 페이지 탐색
- 목록은 요약만 받고, 선택한 제도 상세 원문은 로컬 서버에서 조회
- 새 상담으로 입력과 결과 초기화, 모바일 화면

규칙 기반 체험 모드와 **Google Cloud Gemini 구조화 분류 모드**를 제공합니다. 프로젝트·후불 결제 설정 전에는 체험만 사용할 수 있습니다. 복지 데이터는 2026-10-28 승인받은 정부24 공공서비스(혜택) API에서 실제 수집한 **10,946개 전체 항목**입니다. 화면에는 저장된 수집본을 제공하며, 매 상담마다 외부 API를 호출하지 않습니다. 이 API에 등록되지 않은 민간사업·새 공고까지 모두 포함한다는 의미는 아닙니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 개발 서버는 기본적으로 이 컴퓨터에서만 접속 가능합니다.

```sh
npm test
npm run build
npm start
```

`npm start`는 빌드한 정적 웹과 API를 같은 서버에서 제공합니다. 이미 개발 서버가 실행 중이면 먼저 중단하거나 다른 PORT를 지정하세요. 공개 서비스는 https://onhye.vercel.app 에서 확인합니다.

## Gemini 연결과 구조화 분류

사용자가 Jev의 공개 접근을 독립 구현하고 후불 AI API를 쓰는 방향으로 변경했습니다. 기존 TypeSafe API 호출 경로는 제거했습니다. Jev의 비공개 가중치·RLCD 학습·확률 보정을 복제한 모델은 아닙니다.

- 상황 하나와 이름이 붙은 독립 질문 13개를 한 번의 요청에 보냅니다.
- 분야마다 `relevant / absent / unknown` 중 하나와 상황 원문의 근거 구절을 받습니다.
- Gemini 응답을 JSON 스키마로 제한하고 서버에서 다시 검증합니다. 누락·추가 필드·원문에 없는 근거·잘린 응답을 거부합니다. 관련 있음인데 근거가 없으면 확인 필요로 바꿉니다.
- 생성형 모델의 자가 보고 확률은 신뢰도로 쓰지 않습니다. Jev와 동등한 보정 정확도·지연시간을 주장하지 않습니다.
- 모호한 분야는 화면에서 사용자에게 확인합니다. 제도 안내는 공식 수집본과 고정 문구로 제공하고, AI는 지원 자격을 판정하지 않습니다.

후불 경로는 Google Cloud Vertex AI(현재 문서명 Gemini Enterprise Agent Platform)입니다. AI Studio의 선불 Gemini Developer API를 사용하지 않습니다. 공식 문서와 계정의 ‘후불 - Google Cloud 서비스’ 탭을 확인했습니다. 모델은 현재 제공되는 `gemini-3.5-flash-lite`, global 경로이며 1회 호출·최대 출력 2,048토큰·생성 요청 자동 재시도 없음으로 제한합니다. 입력은 2,000자 이내입니다. 이는 계정 전체의 지출 상한을 의미하지 않습니다.

`.env.local`에는 프로젝트 ID와 `GOOGLE_CLOUD_POSTPAY_CONFIRMED=true`를 설정합니다. 로컬 인증은 Google의 Application Default Credentials(ADC)를 사용하며, 기존 인증 파일은 수정하지 않습니다. 토큰은 브라우저에 전달하지 않습니다. 배포할 때는 별도 런타임 서비스 계정에 필요한 권한을 부여해야 합니다.

```dotenv
GOOGLE_CLOUD_PROJECT=사용할_프로젝트_ID
GEMINI_MODEL=gemini-3.5-flash-lite
GOOGLE_CLOUD_POSTPAY_CONFIRMED=true
```

이 값만으로 인증·결제·API 활성화가 완료되는 것은 아닙니다. 실제 호출은 프로젝트 권한·연결된 후불 결제 계정·`aiplatform.googleapis.com` 활성화와 사용자 전송 동의가 필요합니다. 설정 상태는 호출 성공 여부와 구분하여 표시합니다.

2026-10-28 사용자 승인으로 기존 `Gemini API` 프로젝트(`gen-lang-client-0179618980`)를 사용합니다. 기존에 활성화된 Vertex AI API와 연결된 후불 결제 계정을 확인했고, 다른 프로젝트의 설정은 변경하지 않았습니다. 합성 한국어 입력 6개(복수 관심·부정문·양육·노후·무관 입력·명령 삽입)를 실제 모델로 각 1회 점검하여 모두 기대 분류와 일치했습니다. 요청별 관측 시간은 약 1.2~1.6초였으며 일반 정확도·성능 보장이 아닙니다. 결과는 `docs/gemini-live-check.json`에 저장했습니다. 단위 테스트의 모델 응답은 가상 데이터입니다.

공식 근거: [TypeSafe System One](https://docs.typesafe.ai/concepts/system-one), [AI primer](https://docs.typesafe.ai/introduction/machine-learning-primer), [Google Cloud 결제 주기](https://docs.cloud.google.com/billing/docs/in-product-billing-setup), [모델·구조화 출력 지원](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-5-flash-lite).

## 공공데이터 연결

[행정안전부_대한민국 공공서비스(혜택) 정보](https://www.data.go.kr/data/15113968/openapi.do)의 공식 Swagger v3를 확인하고 무료 API 활용신청·승인을 마쳤습니다. `serviceList`가 지원대상·선정기준·지원내용·신청방법을 함께 제공하므로, 1,000개씩 11페이지를 받아 공식 전체 건수 10,946개와 유일 서비스 ID를 대조했습니다.

| 소관기관 유형 | 수집 건수 |
| --- | ---: |
| 중앙행정기관 | 1,046 |
| 광역시도 | 1,389 |
| 시군구 | 6,503 |
| 공공기관 | 600 |
| 교육청 | 261 |
| 지방공기업 | 562 |
| 지방출자·출연기관 | 585 |
| 합계 | 10,946 |

```sh
npm run data:sync
```

서버 전용 `.env.local`의 `GOV24_API_KEY`를 사용합니다. 기존 중앙부처 API 키와 별개이며 인증키는 요청 헤더에만 보냅니다. 정상 페이지·건수·중복 없는 ID·정부24 HTTPS 링크가 모두 검증된 뒤 `data/benefits.json`을 원자적으로 교체합니다. 빈 페이지·중복 ID·수집 중 건수 변경·오류 시 기존 수집본을 유지합니다. 수집 후 서버를 재시작합니다. 자동 갱신은 설정하지 않았습니다.

전체 수집의 범위는 **정부24 API가 반환한 전체 목록**입니다. 모든 민간 지원사업·현재 접수 여부·각 항목의 최신성을 보장하지 않습니다. 선정기준 등 누락된 원문은 추측해서 채우지 않고 상세 공식 링크로 안내합니다. 수집일과 제공기관 수정일을 구분해 표시합니다.

분야는 공식 서비스분야와 제도명 키워드로 복수 분류합니다. AI도 의료·교육·돌봄·문화·사업·농어업·행정 등을 포함한 13개 분야를 탐색합니다. 분야 분류는 자격 판정이 아닙니다. 추천은 선택한 분야로 후보를 좁히고 입력조건과 직접 관련성을 비교해 30개씩 표시합니다. 소관기관 지역만으로 후보를 제외하지 않습니다. 전체 후보 수와 전체 검색으로 이동하는 경로를 표시합니다.

기관 지역은 기관명이 명시하는 광역 지역만 사용합니다. 기관명이 전국 기관인 경우 지원지역을 임의 확정하지 않습니다. 상세 시군구·거주기간·소득·재산·연령 예외와 현재 신청 여부는 이용자가 공식 안내에서 확인해야 합니다. 전체 검색의 지역 필터는 ‘기관 지역’이며 개인 자격 필터가 아닙니다.

13개 분야 확장 후 장학·의료·창업·복수 관심 합성 입력 4건을 실제 Gemini로 점검해 기대 분류와 일치했습니다. `docs/catalogue-ai-check.json`은 이 제한된 점검 기록이며 일반 정확도 벤치마크가 아닙니다.

## 데이터·개인정보 경계

- 금액·수급 가능성을 생성하거나 보장하지 않습니다. 소득·재산·가구원 범위는 미확인으로 남깁니다.
- 생년월일·주소를 자유문장에서 추측하지 않고, 선택 입력한 정보만 사용합니다.
- 지원받을 사람이 본인인지 가족인지 확인합니다. 나이만으로 복잡한 예외를 임의 탈락시키지 않습니다.
- 상담과 담은 혜택은 React 메모리에만 있습니다. localStorage·데이터베이스·로그에 저장하지 않습니다.
- 체험 모드의 상황 설명은 이 로컬 서버로 전송되지만 제3자 AI에는 전송되지 않습니다.
- Gemini 모드에서 동의한 상황 설명은 Google Cloud에 전송됩니다. 별도 입력한 나이·지역은 Gemini에 보내지 않습니다. 사용자가 상황 설명에 쓴 정보 자체는 전송될 수 있습니다.
- 전화번호·주민번호의 대표 패턴을 차단하지만 모든 개인정보를 감지하는 것은 아닙니다.
- 저장 메모에는 공식 제도 안내만 담습니다. 자유문장과 프로필은 포함하지 않습니다.
- 임상·법률 판단, 신청 대행, 자동 수급 판정은 하지 않습니다.

## 구조

- `src/`: React 화면과 스타일
- `server/domain.mjs`: 입력 검증·관심 분류·추천 후보 구성
- `server/index.mjs`: 같은 출처의 API와 정적 웹 서버
- `server/welfare.mjs`, `scripts/sync-welfare.mjs`: 정부24 전체 목록 수집
- `data/benefits.json`: 현재 제도 안내와 출처
- `tests/`: 분류·미확인 조건·결제 차단·응답 검증·JSON 페이지 수집·HTTP 경계 테스트
- `docs/design.md`, `docs/concept.png`: 구현 범위와 디자인 기준

첫 시제품은 화면 흐름을 검토하기 위한 것으로, 정부24 전체 목록 수집·검색과 Gemini의 제한된 라이브 점검을 완료했습니다. Vercel 공개 배포와 실제 AI 연결을 완료했습니다. 민간 지원사업 전체 수집·일반 정확도 검증은 미완료입니다.

### 상황별 전체 탐색 (2026-10-28)

- 정부24 10,946개 제도에 공식 `supportConditions`를 서비스 ID로 연결했다.
- K-Startup 공고 30,442건(종료 포함)을 별도 `data/announcements.json`에 수집했다. 서로 다른 제도 수를 의미하지 않는다.
- 나이·성별·시도·직업·가구 특성은 명시한 표현만 추출하고 사용자가 확인한다. 분야 미선택은 전체 분야이며, 개인조건 검색 결과는 30개씩 모든 페이지에 접근할 수 있다.
- 공식 대상 표시가 일치하면 우선 정렬한다. 조건 누락은 탈락 사유로 사용하지 않는다. 공식 기본 연령 범위 밖인 경우도 예외 확인 대상으로 남긴다.
- 개인/가구 월소득, 금융재산, 총재산, 부채는 원 단위이며 `null`과 0을 구분한다. 같은 산정 기준의 기계 판독 규칙을 아직 확보하지 못해 금액으로 자동 탈락·자격 확정하지 않는다. 시군구도 공식 상세 조건 확인용이며 자동 지역 판정하지 않는다.
- 확인 화면의 조건은 Gemini에 전송하지 않는다. 자유 입력의 숫자+원 금액은 전송 전에 가린다. 상황 입력은 저장하지 않는다.
- 추가 공식 채널의 실제 수집 건수·수집일·범위·완전성은 데이터 출처 화면에서 확인한다. 첨부파일 조건 전체 해석은 미구현이다.

갱신: `npm run data:sync`(정부24 목록+지원조건), `npm run data:announcements`(K-Startup 공고). 창업 API는 `KSTARTUP_API_KEY` 또는 기존 공공데이터포털 `WELFARE_API_KEY`를 서버 환경에서 사용한다. 갱신 실패 시 기존 파일을 유지한다. 갱신 후 서버 재시작이 필요하다. 주기적 자동 갱신은 설정하지 않았다.

추천에서는 모집 종료 공고를 기본 제외하며, 결과의 체크박스로 모두 포함할 수 있다. 전체 목록에는 종료 공고도 보존한다.

### 공격적 리뷰 수정 (2026-10-28)

- `/api/catalog-meta`는 초기 상담용 요약·미리보기만 반환한다. `/api/catalog`는 서버 검색 및 20건 페이징을 제공한다. 최신 측정: 메타데이터 1,542바이트, 목록 첫 페이지 11,167바이트(기존 28,236,617바이트 전체 응답 제거).
- 추천은 확인한 입력조건 일치 / 필수정보·미검증 조건 / 확인한 조건 불일치로 구분한다. 범용 Y 표시를 과대 가점하지 않는다. 상세 대상·제외조건을 검증하지 못한 제도는 미확인으로 남긴다.
- AI가 추출한 관심은 `preferredTopics`로 전체 검색 중 우선순위에 반영한다. 사용자가 직접 고른 `topics`는 검색 범위를 좁힌다.
- 충돌하는 지역은 비워두고, 가족 검색에서는 본인의 성별·직업·재산을 옮기지 않는다. 가족과 명시적으로 연결된 나이만 추출한다. 부정문은 직업·특수상황별로 처리한다.
- 담은 항목은 브라우저 메모리의 객체 목록으로 유지해 다른 결과 페이지에서도 표시·다운로드할 수 있다. 새 상담에서 지운다.
- 검증한 금액 비교는 2026년 서울형 긴급복지 1인 가구에 한정한다. 기관 산정 기준을 확인한 가구 월소득·가구 금융재산만 비교한다. 개인 금액을 가구 금액으로 간주하지 않는다. 근거와 제한은 `research/public-data/financial-rule-evidence.json`에 보존했다. 적용연도가 지나면 비교를 중단한다. 금융조건 일부 비교일 뿐 최종 자격 판정이 아니다.
- 첫 화면과 출처 화면에서 제도 수, 수집 시 모집 중 공고 수, 추가 채널별 실제 수집 범위와 미수집 부분을 분리한다.


### 추가 채널 실제 수집

`npm run data:channels`로 추가 10개 채널을 수집한다. 일부만 갱신하려면 `npm run data:channels -- youth myhome`처럼 ID를 지정한다.

| ID | 공식 수집 범위 |
| --- | --- |
| youth | 온통청년 공개 통합검색 정책 전체·지원내용 |
| myhome | 승인받은 API 공공임대·공공분양 모집 전체 행 |
| sbiz | 소상공인24 자체·외부 사업공고 공개 API 전체 |
| bizinfo | 기업마당 진행·지난 지원사업 공고 전체 목록 |
| iris | IRIS 종료·예정·진행 전체 공개 목록을 조회하고 공식 상태가 미게시인 자료 제외 |
| arko | 아트누리 지원사업 전체 공개 목록, 공공·민간 주최 혼재 |
| mss | 승인받은 중기부 사업공고 API 전체·본문·첨부 링크 |
| seoul | 청년몽땅정보통 청년정책 공지 및 지역별 청년지원정보 전체 공개 목록 |
| kosaf | 한국장학재단 장학금·학자금 대출 메뉴의 제도·절차 안내 및 전체 공지(모집·행정 공지 혼재) |
| work | 고용24 통합검색 기본 개강일 범위의 모든 훈련과정 페이지 |

마이홈·중기부는 서버의 `WELFARE_API_KEY`를 공공데이터포털 일반 인증키로 사용한다. 별도 `MYHOME_API_KEY`, `MSS_API_KEY`도 지원한다. 활용신청·승인 없이 키만 복사해서는 동작하지 않는다. 다른 수집기는 공식 공개 검색·목록을 조회하며 로그인·유료 API를 우회하지 않는다.

채널별 결과는 검증 후 `data/channels/<ID>.json`에 원자적으로 교체하며 실패하면 기존 파일을 유지한다. 기존 `data/channels.json`보다 새 수집일의 채널별 파일을 우선 사용한다. 공개 대형 목록은 날짜별 `.cache/channels/`에서 이어받는다. 수집 후 앱 서버를 재시작해야 반영된다.

전체 페이지 조회와 특정 시점의 완전한 목록은 구분한다. 수집 중 게시물이 추가·삭제되거나 고유 건수가 달라지는 고용24는 `complete: false`와 관측 건수를 보존한다. 같은 공고를 여러 채널에서 수집할 수 있으므로 합계는 서로 다른 혜택 수가 아니다. 제목·기관·요약 중심의 목록 수집은 상세 첨부를 전부 해석했다는 의미도 아니다. 마이홈은 같은 공고·주택 ID라도 지역·공급수가 다르면 보존하고, 중기부 중복 ID는 첨부 링크를 합친다.


2026-10-28 최종 수집본: 정부24·K-Startup 및 추가 10채널, 총 **144,124건**을 검색·추천 API에 연결했다. 제도·훈련·공지·종료 공고·채널 간 중복을 포함한 집계다. IRIS는 24,705행 조회 후 공식 미게시 5,527행과 중복을 제외한 19,169건을 반영했다. 고용24(18,619건)와 아르코(15,523건)는 전체 페이지를 조회했으나 공식 표기와 차이가 있어 완전성을 미확인으로 표시한다. 44개 테스트·빌드 및 전 채널 검색/상세 HTTP 점검을 통과했다. 원문 수집 범위와 점검 기록은 `research/public-data/collection-progress.json`에 보존했다.

## AI 남용 방어

유료 분류에는 로컬 SQLite·Vercel Firestore의 영속 호출 예산, 세션·CSRF, 중복·동시 요청 제한을 적용합니다. 공개 검색 요청 제한도 Firestore에서 인스턴스 간 공유합니다. 공개/production 모드는 HTTPS Origin 및 Turnstile 설정 없이는 AI를 호출하지 않습니다. 직접 분야 선택과 일반 목록은 유지됩니다. 실제 한도·중단 명령·배포 제약은 [구현된 방어와 운영 안내](research/security/implemented-defense.md)를 확인하세요.

### 전체 리뷰 수정

개발 정적 제공에서 비공개 상태·SQLite·보조파일·심볼릭 링크를 차단합니다. 유효한 API 경로만 요청 제한에 기록하며 IP 전체 한도도 적용합니다. 한국어 JSON은 바이트를 합친 뒤 디코딩합니다. 과거·부정·금액 변경이 섞인 입력은 보수적으로 미확인으로 남깁니다. 결과 분야 탭은 서버에서 필터 후 페이지를 계산하고 페이지 이동 때 유지됩니다. 담은 혜택은 현재 입력조건으로 공통 추천 로직을 다시 실행해 평가합니다.

## 오류 기록·상태 점검

서버·브라우저 오류는 개인정보와 원문을 제외한 구조화 로그로 기록합니다. 이 Mac에는 5분 간격 상태 점검과 Vercel 오류 수집 작업을 등록했습니다. `npm run monitor:status`로 최근 결과를 보고, `npm run monitor:once`로 즉시 점검할 수 있습니다. 로그 위치·수집 범위·중단 방법·제약은 [모니터링 운영 안내](docs/monitoring.md)를 확인하세요.
